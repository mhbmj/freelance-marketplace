# پلتفرم بازار کار فریلنسری (Freelance Marketplace)

این پروژه در چارچوب درس **آزمایشگاه مهندسی نرم‌افزار** (مدرس: مهندس میهن‌پور) طراحی و پیاده‌سازی می‌شود.

## اطلاعات تیم
* **نام تیم:** مهتاب (Mahtab)
* **اعضای تیم:** مهتاب مروج (Mahtab Moravej)

## پشته فناوری (Technology Stack)
* **Frontend:** React.js
* **Backend:** Django & Django REST Framework
* **Database:** PostgreSQL

## ساختار مخزن (Repository Structure)
* `docs/requirements.md`: سند جامع تحلیل نیازمندی‌ها (FRها، NFRها، تحلیل پلتفرم‌های مشابه و اولویت‌بندی MVP)
* `docs/`: مستندات پروژه و فازهای مختلف مهندسی نرم‌افزار
